# nhaoes-website

논리 기반의 전략 수립(Logic-driven Strategy)과 정량적 증거 중심의 실행(Evidence-based Execution)을 시각적으로 담아낸 웹 포트폴리오 프로젝트입니다.

---

## 주요 기능 및 설계 특징

### 1. 인터랙티브 사용자 경험 (UX)
* 글래스모피즘 인터페이스: 심해를 연상시키는 네이비 톤(`#0A192F`) 배경 위에 세련된 유리를 얹은 듯한 Glassmorphism 스타일 카드를 적용하여 현대적이고 프로페셔널한 느낌을 줍니다.
* 타이핑 애니메이션: 메인 헤더 진입 시 핵심 가치를 담은 한글 슬로건이 실시간으로 작성되는 타이핑 효과를 구현했습니다.
* 동적 프로그레스 바: 스크롤이 기술 역량 영역(`Proficiency`)에 도달하면 인터섹션 옵저버(`IntersectionObserver`)가 감지하여 그래프가 0%부터 부드럽게 차오르는 애니메이션을 실행합니다.

### 2. 전략적 이팩트 프레임워크 (Layered Process Grid)
단순한 텍스트 나열을 넘어, 문제 인식부터 성과 창출까지의 단계를 깊이감 있는 4단계 레이아웃으로 시각화했습니다.
* 3D 입체 레이어 구조: 1단계(배경)에서 4단계(결과)로 갈수록 Blur 값이 옅어지고 투명도가 올라가며, 마우스 오버 시 입체적으로 튀어나오는 마이크로 인터랙션을 설계했습니다.
* 최종 결과 글로우 효과: 정량적 성과를 보여주는 4단계(`STEP 04`) 카드에는 회전하는 그라데이션 보더 테두리(`Result Glow`)를 적용하여 분석가가 만들어낸 비즈니스 임팩트를 강조합니다.
